# Team Kaushya website

Static site for GitHub Pages. No build step.

## Publish
1. Create a public repository and upload every file in this folder (index.html, style.css, script.js, .nojekyll, README.md).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Your site appears at https://USERNAME.github.io/REPO/ in a minute or two.

## Edit before publishing
- index.html: replace `your-email@example.com` in the Contact section.
- script.js: the sorter simulation uses made-up limits (1.5 g, colour spread 25). Match them to your prototype.
- Check the silk journey facts (script.js, `S` array) with your mentors or the Central Silk Board before submitting.
